Recommended sizes

The site works with any size, but these give the sharpest result on a large monitor without making the page slow. Always landscape — a portrait photograph will be cropped top and bottom.

WhereSizeShapeNotes
Home slider1920 × 8602.2 : 1 Widest image on the site. Keep the subject right of centre — the text panel covers the left half.

Keep each file under about 400 KB. Save as JPEG at around 80% quality. A photograph straight off a phone is often 4–8 MB, which makes the page slow to load on a mobile connection for no visible gain.

Form delivery

Sending straight from the website. The enquiry form and the quote specification are posted to send.php, which sends the email from the server. Nothing opens Gmail or Outlook. Before go-live, open send.php and fill in the sending mailbox and password near the top of the file. Until that is done the forms still work, but mail is more likely to be filtered as spam.
How saving works. Changes are held in this browser straight away, so you can review the live site immediately. To make them permanent for everyone, download the content file below and replace data/content.js on the server. On WordPress this step disappears — saving writes to the database directly.
Two ways to add an image. Beside every file picker there is a box for a filename. Putting images into assets/img/ with GoDaddy File Manager or FTP and typing the filename is the better way: it works for any number of images and costs nothing. Choosing a file instead stores the whole image inside the content file, and the browser only allows about 5 MB of unpublished changes in total — fine for one or two, not for a batch.
